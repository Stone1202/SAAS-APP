## 四、用例卡使用说明

### 原型内嵌用例卡
每个原型页面右下角有"用例卡"浮动按钮，点击弹出该页所有 UC 的卡片详情（含前置条件/基本流程/备选流程/后置条件/入口路径/接口标注/状态机等研发友好字段）。

### 原型总览页
- **独立地址**：`/#/prototype`
- **入口**：运营后台 / 租户后台左侧栏底部「原型总览」
- **功能**：左侧功能树整合三端 30 页面 + 13 弹窗；中间 iframe 高保真预览；右侧展示用例卡 / 文档中心 / 业务规则 / 数据实体 / 流程图 / 状态机。

### 数据源文件
- APP端：`src/data/use-cases/app-use-cases.ts`（31个UC）
- 运营后台：`src/data/use-cases/admin-use-cases.ts`（15个UC）
- 租户后台：`src/data/use-cases/tenant-use-cases.ts`（6个UC）
- 统一导出+索引：`src/data/use-cases/index.ts`

### 接入方式
页面通过 `useUseCaseCard` composable 接入：
```typescript
import { useUseCaseCard } from '@/composables/useUseCaseCard';
const { ucDrawerVisible, ucCards, ucDrawerTitle } = useUseCaseCard('PG-xxx', '页面名称');
```

### 字段说明（研发友好模板v4）
| 字段 | 说明 |
|------|------|
| ucId/ucName/description/priority | UC基本信息 |
| fnId/pgId/system/module/page | 功能/页面归属 |
| route/component/terminal | 页面路由/组件名/终端 |
| participants/affectedData | 参与人/影响数据实体 |
| precondition/basicFlow/altFlow/postcondition | 用例四要素 |
| entryPaths | 入口路径表(序号/入口/来源页面/触发操作) |
| apiCalls | 接口标注(步骤/接口/说明) |
| stateMachine | 状态机关联(实体/状态/当前处理) |
| elementHelps | 元素级帮助(id/target/content/relatedUC/relatedBR) |
| **businessRules** | **v3.1.39新增**：关联业务规则编号列表 |
| **dataEntities** | **v3.1.39新增**：涉及数据实体编号列表 |
| **relatedPages** | **v3.1.39新增**：关联页面pgId列表 |
| **hifiPrototypeUrl** | **v3.1.39新增**：高保真原型完整URL |
| **acceptanceCriteria** | **v3.1.39新增**：验收标准条目 |
| **designDocAnchor** | **v3.1.39新增**：设计文档锚点 |

1. **文案统一**：前端推荐区文案统一为「直播推荐 / 商品推荐」；商城 Tab「精选商品 / 精选直播」作为独立功能入口名保留。

4. **入口扩展**：`AdminLayout.vue` / `TenantLayout.vue` 左侧栏底部新增「原型总览」入口。
5. **五方一致性**：PRD(52UC/30页面/13弹窗) ↔ design-map.json ↔ 用例卡数据源 ↔ 代码路由 ↔ 原型总览页全量对齐。
