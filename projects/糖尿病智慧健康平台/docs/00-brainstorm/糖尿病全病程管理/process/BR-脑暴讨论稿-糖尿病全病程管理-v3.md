# 糖尿病智慧健康平台 — 全平台脑暴讨论稿 v3（全面重论）

> **议题**：糖尿病全病程管理  
> **项目**：糖尿病智慧健康平台  
> **脑暴类型**：Planning（整体讨论，不限迭代范围）  
> **日期**：2026-07-27  
> **原则**：本次讨论不预设Phase边界，完整梳理三端能力全景

---

## 一、重论背景

v1/v2 两轮脑暴预设了迭代范围（15个FN/分Phase），用户反馈**不应在脑暴阶段锁定迭代边界**，应先完整梳理平台全貌，再做范围取舍。

本次 v3 重论原则：
- ✅ 穷举三端全部业务能力，不遗漏
- ✅ 不设定Phase/优先级/开发顺序
- ✅ 以"这个平台最终长什么样"为讨论目标
- ✅ 让用户在看完全景后自行决定从哪里开始

---

## 二、讨论前提：三端定位（已确认）

| 端 | 定位 | 用户 | 核心能力边界 |
|----|------|------|-------------|
| **小程序** | 轻量前端·获客入口 | 潜在患者/粉丝 | 知识传播、食品交易、咨询入口→企微客服、引导安装APP |
| **APP** | 重度前端·业务闭环 | 患者/家属/医生 | 问诊、处方、商城、支付、营销、交易、直播、课程、慢病管理、档案管理、预警、血糖仪器连接 |
| **业务后台** | 运营中枢·能力共享 | 运营/管理员 | 商品管理、订单管理、入驻审核、营销引擎、内容CMS、SCRM、数据看板、全流程闭环支撑 |

### 三端关系

```
小程序（获客+食品交易+引流）
    ↓ 企微SCRM承接 → 引导安装APP
APP（完整业务闭环·商业变现）
    ↓ 所有业务请求
业务后台（统一后端·全流程支撑）
```

|--------|------|------|------|

### 4.3 关键业务闭环

```
闭环1：小程序获客 → 企微承接 → 标签打标 → 引导下载 → APP激活
闭环2：血糖异常 → 预警推送 → 在线问诊 → 开具处方 → 商城购药 → 用药记录 → 血糖改善
闭环3：商品入驻 → 上架审核 → 双端展示 → 用户下单 → 支付 → 发货 → 收货 → 结算
闭环4：直播 → 商品卡片 → 一键购买 → 到货 → 复购
闭环5：课程学习 → 知识掌握 → 行为改善 → 血糖达标 → 社区分享 → 吸引新用户
闭环6：用户活跃度下降 → 流失预警 → 定向召回（优惠券/提醒）→ 重新活跃
```
