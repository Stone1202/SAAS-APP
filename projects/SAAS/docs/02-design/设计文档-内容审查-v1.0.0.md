## 第1章 交互原则

### 1.1 核心交互原则

| 原则 | 说明 | 应用场景 |
|---|---|---|
| **实时优先** | 违规告警必须实时展示，不延迟不缓冲 | 中控室内容审查Tab实时推送 |
| **依据完整** | 每条违规处置必须附完整依据链，便于判断 | 违规列表+处置弹窗展示依据 |
| **渐进处置** | 处置从轻到重（记录→警告→断流→封禁），可加严不可放宽 | 处置操作区策略映射 |
| **配置优先** | 能配置的不开发，能复用的不自建 | V1腾讯云配置优先策略 |
| **隔离自治** | 平台与租户词库隔离，租户只能加严不可放宽 | 敏感词库管理 |
| **状态可溯** | 所有操作有记录，所有状态可追溯 | 违规记录+处置日志 |

### 1.2 尼尔森十大原则对照

| 原则 | 应用 |
|---|---|
| 系统状态可见 | 中控室审查状态（运行中/异常）+违规数实时更新 |
| 系统与真实世界匹配 | 违规类型用业务术语（涉黄/涉暴/广告法），不用技术术语 |
| 用户控制与自由 | 处置操作可撤回（记录→断流不可逆除外），忽略可改记录 |
| 一致性与标准 | 复用SAAS平台现有组件规范（表格/表单/弹窗/按钮） |
| 错误预防 | 断流操作需二次确认+展示违规依据 |
| 识别而非回忆 | 违规列表展示完整信息，不需记忆 |
| 使用灵活高效 | 快捷键支持（Enter=记录/Esc=忽略/Ctrl+D=断流） |
| 美观简约 | 中控室Tab信息密度高但层次分明（提示区/列表/操作区） |
| 帮助用户识别诊断恢复 | 擦音异常/同步失败有明确错误提示+重试入口 |
| 帮助文档 | 敏感词库管理有操作指引+6类不可降级说明 |

## 第4章 页面交互

### 4.1 PG-AUDIT-PC-001 中控室-内容审查Tab（★V1核心）

**所属页面**：直播中控室（嵌入Tab）
**关联FN**：FN-AUDIT-PC-002（回调接收）+ FN-AUDIT-PC-003（中控室审查Tab）
**关联UC**：UC-AUDIT-002

#### 页面结构

| 区块 | 编号 | 内容 | 交互 |
|---|---|---|---|
| 提示区 | B-001 | 审查状态（运行中/异常）+ 当前违规数 + 最新告警提示 | 实时刷新，红色/黄色/蓝色告警 |
| 违规列表区 | B-002 | 违规记录表格（时间/类型/内容片段/级别/处置建议/依据/状态） | 点击行展开详情，支持排序/筛选 |
| 处置操作区 | B-003 | 每行末尾处置按钮组（记录BTN-001/断流BTN-002/忽略BTN-003） | 点击触发处置弹窗或直接执行 |

#### 交互流程

```
1. 中控室加载 → 内容审查Tab自动激活（如有违规）或正常展示（无违规）
2. 腾讯云回调到达 → 提示区实时更新告警 + 列表新增违规行
3. 运营点击违规行 → 展开违规详情（内容片段/证据/回调原始数据）
4. 运营点击处置按钮 → 弹出处置弹窗（M-001）
5. 运营确认处置 → 执行处置 + 更新状态 + 记录日志
6. 30秒未处置 → 系统自动记录 + 告警升级
```

#### 违规列表表格字段

| 列 | 字段 | 宽度 | 说明 |
|---|---|---|---|
| 1 | 违规时间 | 160px | yyyy-MM-dd HH:mm:ss |
| 2 | 违规类型 | 100px | 涉黄/涉暴/违禁词/广告法... |
| 3 | 违规级别 | 80px | 高(红)/中(黄)/低(蓝) 标签 |
| 4 | 违规内容 | 200px | 音频片段URL/截图缩略图 |
| 5 | 命中敏感词 | 120px | 命中的具体词汇 |
| 6 | 处置建议 | 100px | pass/review/block |
| 7 | 处置依据 | 80px | 点击查看完整依据 |
| 8 | 状态 | 80px | 待处理(红)/已记录(灰)/已断流(红)/已忽略(灰) |
| 9 | 操作 | 180px | 记录/断流/忽略 按钮 |
