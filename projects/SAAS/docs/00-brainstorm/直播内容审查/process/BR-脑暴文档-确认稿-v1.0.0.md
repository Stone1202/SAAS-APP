## 一、议题背景与业务构想

### 1.1 业务构想

构建SAAS级直播内容审查系统，为SCRM平台客户提供直播内容安全保障能力。系统覆盖直播全生命周期的内容合规管理：实时审核→智能擦除→回放审核→回放擦除，支持多租户个性化审核策略。

### 1.2 核心功能（四大模块）

| 模块 | 描述 | 核心价值 |
|------|------|----------|
| **实时擦音** | 直播过程中AI实时识别违规音频并擦除（静音/蜂鸣声） | 违规内容零秒流出，品牌与合规风险实时阻断 |
| **回放擦音** | 直播结束后对回放内容进行审核+智能擦除遗留违规片段 | 回放长期留存无合规隐患 |
| **平台管控** | 审核模板配置/回调配置/关键词库管理/审核事件处置 | 运营人员一站式管控审核策略 |
| **租户个性化** | 多租户隔离的审核策略/关键词库/擦除策略/处置规则 | 不同租户按行业合规要求定制审核标准 |

### 1.3 三源输入

- **自然语言描述**：直播内容审查——实时擦音+回放擦音+平台管控+租户个性化
- **领域知识**：腾讯云直播质检（tencent-live-moderation.yml v2.0.0）
- **API文档**：腾讯云CSS截图与审核API（CreateLiveSnapshotRule等9个API）

| 领域名 | 文件路径 | 版本 | 关键摘要 |
|--------|----------|------|----------|

### 2.1 领域知识关键要点

**审核类型**：
- 图片识别：鉴黄 + OCR文字识别 + 自定义关键词库匹配
- 音频识别：自定义关键词库匹配（仅支持中文音频）
- 音频文字识别：用于智能擦除功能（不触发审核回调）

**智能擦除**：
- 音频擦除：静音擦除（默认）/ 蜂鸣声擦除（Beep滴滴声）
- 隐私擦除：人脸模糊 / 车牌模糊 / 旗帜模糊
- 依赖：必须绑定审核模板中已开启"音频文字识别"的模板
- 约束：智能擦除与字幕功能互斥；绑定/修改仅影响新推流

**回调事件**：
- 事件类型315：音频审核事件通知（含hit_flag/score/label/suggestion/asr_text等核心字段）
- 智能擦除回调：擦除执行结果通知
- 截图回调 + 推流/断流回调

**API清单**：
- CreateLiveSnapshotRule / CreateLiveSnapshotTemplate / CreateScreenshotTask
- DeleteLiveSnapshotRule / DeleteLiveSnapshotTemplate
- DescribeLiveSnapshotRules / DescribeLiveSnapshotTemplate / DescribeLiveSnapshotTemplates
- ModifyLiveSnapshotTemplate

**计费**：
- 图片审核：0.2294 USD / 千张
- 音频审核：0.0021 USD / 分钟
- 智能擦除：CSS增值费用 + MPS智能识别费用

**关键约束**：
- 审核模板绑定后5-10分钟生效
- 绑定/修改/解绑仅影响新推流，不影响正在进行的流
- 默认仅返回不合规结果
- 音频审核仅支持中文音频

## 三、API分析清单（传递给BA+Arch继承）

### 3.1 API能力清单

| API名称 | 功能 | 关键参数 |
|---------|------|----------|
| CreateLiveSnapshotRule | 创建截图规则 | DomainName, AppName, StreamName, TemplateId |
| CreateLiveSnapshotTemplate | 创建截图模板 | ScreenshotInterval(2-300s), CosCloudC(), IsVod |
| CreateScreenshotTask | 创建截图任务 | SourceType, DomainName, AppName, StreamName, ScreenshotInterval |
| DescribeLiveSnapshotRules | 获取截图规则列表 | DomainName, AppName, StreamName |
| DescribeLiveSnapshotTemplates | 获取截图模板列表 | 无必填 |
| ModifyLiveSnapshotTemplate | 修改截图模板配置 | TemplateId, ScreenshotInterval, CosCloudC |
| DeleteLiveSnapshotRule | 删除截图规则 | DomainName, AppName, StreamName |
| DeleteLiveSnapshotTemplate | 删除截图模板 | TemplateId |

### 3.2 技术约束清单

- **签名验证**：回调需callback_key签名验证（sign=MD5(key+t)）
- **幂等性**：截图规则按DomainName+AppName+StreamName唯一
- **生效延迟**：配置变更后5-10分钟生效，仅影响新推流
- **存储依赖**：不合规截图/音频需存储到COS存储桶
- **互斥约束**：智能擦除与字幕功能互斥

### 3.3 异常场景清单

| 错误场景 | 处理建议 |
|----------|----------|
| COS存储桶不可写 | 审核证据丢失，需告警+重试机制 |
| 回调URL不可达 | 审核事件丢失，需回调重试+补偿查询 |
| 智能擦除授权过期 | MPS权限失效，擦除功能降级为仅审核不擦除 |
| 审核模板未绑定 | 推流无审核保护，需推流前校验 |

### 5.1 发散阶段

#### [运营部][王运营]
引用领域知识《腾讯云直播质检》v2.0.0：审核配置流程包含6步——创建审核模板→配置截图间隔+音频分片→配置COS存储→创建回调模板→绑定域名→5-10分钟生效。

建议系统管控台需要覆盖这6步配置流程，但要做租户级隔离：每个租户独立配置审核模板和回调模板。截图间隔默认2秒（最细粒度），音频分片默认15秒。COS存储桶按租户隔离，路径格式 `/Audit/{租户ID}/{Year}-{Month}-{Day}/`。

#### [业务部][李业务]
引用领域知识《腾讯云直播质检》v2.0.0：业务泳道有5条——运营人员、腾讯云CSS、SAAS平台、主播、观众。SAAS平台的核心动作是"接收回调通知→展示审核事件→人工处置（断流/忽略）→审核数据看板"。

建议业务流程分两条主线：
1. **实时审核线**：推流→CSS截图/音频分片→AI审核→违规触发回调→SAAS展示事件→运营处置
2. **回放审核线**：直播结束→生成回放→提交回放审核→AI识别遗留违规→审核人员确认→执行擦除→安全回放上线

回放擦音是关键差异点：实时擦音由CSS自动执行，回放擦音需要审核人员确认后才执行，避免误擦。

#### [产品部][赵产品]
引用领域知识《腾讯云直播质检》v2.0.0：智能擦除有两种模式——静音擦除（默认）和蜂鸣声擦除。还有隐私擦除（人脸/车牌/旗帜模糊）。智能擦除依赖"音频文字识别"配置。

建议产品架构分四层：
1. **接入层**：租户管理 + 推流域名绑定 + CSS配置同步
2. **审核层**：实时审核（CSS回调驱动）+ 回放审核（批量审核任务）
3. **擦除层**：实时擦音（CSS智能擦除）+ 回放擦音（审核确认后擦除）
4. **管控层**：审核策略 + 关键词库 + 事件处置 + 数据看板

租户个性化要支持：自定义关键词库、擦除策略选择（静音/蜂鸣声）、置信度阈值配置、处置规则自动化（高置信度自动断流、中置信度转人工复审）。

#### [设计部][陈设计]
从交互体验角度，审核事件列表需要支持：按置信度排序、按违规类型筛选、按时间范围查询。违规证据展示需要同时展示截图（如有）和ASR文本（音频转写内容）。

审核看板需要展示：实时审核统计（今日审核次数/违规率/擦除次数）、趋势图（7天/30天）、租户维度对比。

处置操作需要快速响应：一键断流、一键忽略、批量审核。断流操作需要二次确认防误操作。

#### [开发部][张开发]
引用领域知识《腾讯云直播质检》v2.0.0：回调事件类型315包含hit_flag/score/label/suggestion/asr_text等核心字段。回调需要callback_key签名验证（sign=MD5(key+t)）。

技术架构建议：
- **回调接收服务**：独立微服务接收CSS回调，签名验证→事件持久化→事件分发
- **事件存储**：PostgreSQL存储审核事件（结构化查询）+ COS存储证据文件（截图/音频）
- **实时推送**：WebSocket推送到前端审核事件列表（运营实时可见）
- **租户隔离**：每租户独立CSS配置（审核模板ID + 回调模板ID + COS存储桶）
- **回放审核**：异步任务队列，批量提交回放片段审核

引用领域知识：智能擦除与字幕功能互斥，需在配置时校验提醒。审核模板绑定后5-10分钟生效，配置变更需提示用户"仅影响新推流"。

#### [测试部][刘测试]
引用领域知识《腾讯云直播质检》v2.0.0：关键注意事项包含8条——5-10分钟生效、仅影响新推流、默认仅返回不合规结果、音频仅支持中文、智能擦除依赖音频文字识别、智能擦除与字幕互斥、首次需授权MPS、COS公开读取可能被封禁。

测试重点：
1. 回调签名验证（错误签名/过期签名/重放攻击）
2. 租户隔离（A租户的审核事件不能泄露给B租户）
3. 智能擦除互斥校验（同时配置字幕和擦除时的降级处理）
4. 回调补偿机制（回调URL不可达时的重试+补偿查询）
5. 多租户并发推流审核（性能压测）
6. 回放擦音的误擦率（审核人员确认后再擦除，降低误擦）

### 5.2 收敛阶段

归并相似方案，淘汰不可行方案：

**保留方案**：
1. 四层产品架构（接入/审核/擦除/管控）——各部门一致认可
2. 双主线业务流程（实时审核线 + 回放审核线）——业务部+运营部共识
3. 租户级隔离配置（审核模板/回调模板/COS存储桶/关键词库）——产品部+开发部共识
4. WebSocket实时推送审核事件——开发部+设计部共识
5. 回放擦音需人工确认后再执行——业务部+测试部共识（降低误擦风险）

**淘汰方案**：
1. ~~全量自动擦除（不经过人工确认）~~——测试部指出误擦率高，影响正常直播体验
2. ~~自建AI审核引擎~~——开发部指出成本过高且准确率不如腾讯云CSS，建议集成而非自建
3. ~~审核回调同步处理~~——开发部指出同步处理会导致回调超时，改为异步持久化+事件分发

### 5.4 定调阶段

**共识方案**：

SAAS直播内容审查系统基于腾讯云CSS直播审核能力集成，采用四层架构（接入/审核/擦除/管控），支持多租户个性化配置。核心能力包括：

1. **实时擦音**：集成CSS智能擦除（静音/蜂鸣声），违规音频实时替换，观众零感知延迟
2. **回放擦音**：异步审核任务+人工确认+智能擦除，确保回放无遗留违规
3. **平台管控**：审核模板/回调模板/关键词库/智能擦除全链路配置，WebSocket实时事件推送
4. **租户个性化**：每租户独立审核策略/关键词库/擦除策略/置信度阈值/处置规则

## 六、冲突仲裁记录

| 冲突点 | 冲突方 | 仲裁结论 | 理由 | 备选方案 |
|--------|--------|----------|------|----------|
| 回放擦音是否自动执行 | 业务部(自动) vs 测试部(人工确认) | **人工确认后执行** | 误擦率高影响正常内容，人工确认降低误擦风险 | 高置信度(>90)可配置为自动擦除 |
| AI审核引擎自建 vs 集成 | 开发部(集成) vs 业务部(自建) | **集成腾讯云CSS** | 自建成本高且准确率不足，集成快速上线 | 后续可接入多AI引擎做交叉验证 |
| 回调处理同步 vs 异步 | 开发部(异步) vs 设计部(同步展示) | **异步持久化+WebSocket推送** | 同步处理回调超时风险高，异步保证可靠性 | 前端体验上WebSocket保证实时感知 |
