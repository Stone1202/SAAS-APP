## 一、核心需求描述

### 需求背景

主播在直播过程中可能出现违禁词（涉黄/涉暴/公共安全/社会安全/违法乱纪/广告法等），需要对主播的直播内容（音视频流）进行实时内容审查和擦音处理。直播完成后的回放文件也需要进行事后擦音处理。

### 核心需求

1. **实时擦音**：主播直播中出现违禁词时，实时进行擦音处理（敏感词消音）
2. **回放擦音**：直播完成后，回放文件也需要擦音处理
3. **平台级运营管控**：内容审查属于平台级别的运营管控
4. **租户继承+个性化扩展**：租户可继承平台管控基础上个性化扩展
5. **租户申请降级/提升管控力度**：租户可向平台申请降低或提升管控力度

### 需求边界（明确不交叉）

| 管控对象 | 审查内容 | 技术方案 | 本次需求 |
|---|---|---|---|
| **主播直播内容** | 音频/视频流（推流内容） | 腾讯云直播审核+擦音 | ✅ 是 |
| **观众文本消息** | 弹幕/聊天消息 | 腾讯云IM云端审核 | ❌ 否（已有/独立） |

## 四、技术方案

### 实时擦音（直播中）

```
主播推流 → 腾讯云直播 → 审核模板（配置：敏感词消音+自定义词库）
                              ↓
                    实时审核+自动擦音（腾讯云完成）
                              ↓
                    回调通知 → 业务系统全量接收
                              ↓
                    中控室展示违规告警 → 运营处置（记录/断流）
```

- 腾讯云支持：实时擦音+事后擦音，精度较高，支持自定义敏感词库
- 配置部分：腾讯云控制台配置审核模板+敏感词库
- 开发部分：回调接收+中控室审查Tab+处置流程

### 回放擦音（直播后）

```
直播结束 → 回放文件生成（CDN/对象存储）
                ↓
        立即触发回放擦音（不开放未擦音版本）
                ↓
        AMS音频审核API → 擦音处理 → 更新回放文件
                ↓
        用户观看/下载的都是擦音后版本
```

- 时机：回放文件生成后立即擦音，擦音完成后才开放回放观看
- 用户不会看到未擦音版本

### 两套方案衔接

```
实时擦音（腾讯云直播审核）    回放擦音（AMS音频审核API）
     ↓                           ↓
     └───── 共享自定义敏感词库 ──────┘
               ↓
        平台级敏感词库管理（一套词库两处使用）
```

### 中控室内容审查Tab设计

```
中控室 → 内容审查Tab（V1新增）
├── 提示区（顶部）
│   ├── 实时违规告警提示（红/黄/蓝三级）
│   ├── 当前违规数统计
│   └── 审查状态（运行中/异常）
├── 违规列表区（中部）
│   ├── 违规时间
│   ├── 违规类型（涉黄/涉暴/违禁词/广告法...）
│   ├── 违规内容片段（音频片段/截图）
│   ├── 违规级别（高/中/低）
│   ├── 腾讯云处置建议
│   ├── 处置依据（完整依据链，便于判断）
│   └── 处置状态（待处理/已处理/已忽略）
└── 处置操作区（每条违规）
    ├── 记录（记录违规事件，不打断直播）
    ├── 断流（切断推流，终止直播）
    ├── 查看详情（完整违规数据+回调原始数据）
    └── 处置备注（运营填写处置理由）
```

### 回调数据全量接收

```yaml
callback_data:
  # 基础信息
  - stream_id: "推流ID（关联场次）"
  - domain: "推流域名"
  - app: "应用名"
  - timestamp: "回调时间戳"
  # 违规信息
  - audit_type: "审核类型（音频/视频/截图）"
  - violation_type: "违规类型（涉黄/涉暴/违禁词/广告法...）"
  - violation_level: "违规级别（高/中/低）"
  - violation_content: "违规内容片段（音频片段URL/截图URL）"
  - violation_time: "违规发生时间（推流中的时间点）"
  # 处置建议
  - suggestion: "腾讯云处置建议（pass/review/block）"
  - confidence: "置信度（0-100）"
  - keyword: "命中的敏感词（如有）"
  - keyword_category: "敏感词分类"
  # 处置依据
  - evidence_url: "证据文件URL（音频片段/截图）"
  - raw_callback: "腾讯云回调原始JSON（全量保存）"
  # 擦音信息
  - audio_muted: "是否已擦音（true/false）"
  - mute_duration: "擦音时长（秒）"
  - mute_start_time: "擦音起始时间点"
```

## 五、管控边界

### 不可降级类（6类，平台设定，租户绝对不可降低）

| 类别 | 说明 | 来源 |
|---|---|---|
| 涉黄 | 色情/低俗内容 | 法律法规 |
| 涉暴 | 暴力/恐怖内容 | 法律法规 |
| 公共安全 | 危害公共安全内容 | 法律法规 |
| 社会安全 | 危害社会安全内容 | 法律法规 |
| 违法乱纪 | 违法犯罪内容 | 法律法规 |
| 广告法 | 违反广告法内容 | 《广告法》 |

### 租户可个性化扩展

| 扩展类型 | 说明 | 上限 |
|---|---|---|
| 增加敏感词 | 在6类不可降级基础上增加自有敏感词 | 无上限 |
| 加严审查规则 | 提高审查频率/降低置信度阈值 | 不可低于平台基础 |
| 加严处置策略 | 在平台处置基础上加严 | 不可低于平台处置 |
| 申请降级平台基础词库 | 非不可降级类的平台词库可申请降级 | 需平台审批 |

### 敏感词库体系（V2）

```
平台级词库（PlatformKeywordLib）
├── 不可降级类（6类，平台设定，租户不可修改）
│   ├── 涉黄/涉暴/公共安全/社会安全/违法乱纪/广告法
├── 平台基础词库（平台设定，租户可申请降级）
│
租户级词库（TenantKeywordLib）
├── 租户扩展词库（在平台基础上增加，不可减少不可降级类）
├── 租户个性化词库（租户自定义新增）
│
生效词库 = 平台不可降级类 ∪ 平台基础词库 ∪ 租户扩展词库 ∪ 租户个性化词库
（并集，租户只能增加不能减少不可降级类）
```

### 租户隔离机制

- 腾讯云支持按推流域名关联不同审核模板+不同敏感词库
- 每个租户的推流域名关联该租户的生效词库
- 平台词库变更→同步到所有租户的腾讯云配置
- 租户词库变更→只同步到该租户的腾讯云配置

## 七、三流草图

### 业务流

```
平台运营 → 配置审核模板+敏感词库（腾讯云控制台）
     ↓
租户 → 继承平台管控+个性化扩展
     ↓
主播 → 开始直播（推流）
     ↓
腾讯云 → 实时审核+自动擦音
     ↓
回调通知 → 业务系统全量接收
     ↓
中控室 → 展示违规告警 → 运营处置（记录/断流）
     ↓
直播结束 → 回放文件生成 → 立即回放擦音
     ↓
用户观看/下载擦音后版本
```

### 信息流

```
腾讯云审查 → 回调数据（违规类型/内容片段/处置建议/证据）
     ↓
业务系统 → 全量存储回调数据
     ↓
中控室 → 实时展示违规列表
     ↓
运营处置 → 处置记录（记录/断流+处置依据+处置备注）
     ↓
违规统计 → 违规消息数/处置数/擦音覆盖率
     ↓
平台看板 → 违规趋势分析
```

### 资金流

```
本次需求无直接资金流（内容审查是管控能力非交易能力）
间接资金流：违规处置→终止直播→影响GMV（需在统计看板关联）
```
