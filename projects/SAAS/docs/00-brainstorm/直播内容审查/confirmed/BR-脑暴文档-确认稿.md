## 一、议题背景与业务构想

### 1.1 业务构想

构建SAAS级直播内容审查系统，为SCRM平台客户提供直播内容安全保障能力。系统覆盖直播全生命周期的内容合规管理：实时审核→智能擦除→回放审核→回放擦除，支持多租户个性化审核策略。

### 1.2 核心功能（四大模块）

| 模块 | 描述 | 核心价值 |
|------|------|----------|
| **实时擦音** | 直播过程中AI实时识别违规音频并擦除（静音/蜂鸣声） | 违规内容零秒流出，品牌与合规风险实时阻断 |
| **回放擦音** | 直播结束后对回放内容调用AMS API审核+擦除遗留违规片段 | 回放长期留存无合规隐患 |
| **平台管控** | 审核开关管理/回调接收/中控室展示/处置操作/擦音模式切换 | 运营人员一站式管控审核策略 |
| **租户个性化** | 多租户隔离的敏感词库/审查规则/处置策略/降级申请 | 不同租户按行业合规要求定制审核标准 |

### 1.3 三源输入

- **自然语言描述**：直播内容审查——实时擦音+回放擦音+平台管控+租户个性化
- **领域知识**：腾讯云直播质检（tencent-live-moderation.yml v2.0.0）

### 3.1 领域知识关键要点

**审核类型**（来源：tencent-live-moderation.yml）：
- 图片识别：鉴黄 + OCR文字识别 + 自定义关键词库匹配
- 音频识别：自定义关键词库匹配（仅支持中文音频）
- 音频文字识别：用于智能擦除功能（不触发审核回调）

**智能擦除**（来源：tencent-live-moderation.yml + 已有PRD）：
- 实时擦音：CSS智能擦除（静音/蜂鸣声），腾讯云自动执行
- 回放擦音：AMS音频审核API，业务系统调用，擦音完成后才开放观看
- 依赖：必须绑定审核模板中已开启"音频文字识别"的模板
- 约束：智能擦除与字幕功能互斥；绑定/修改仅影响新推流

**回调事件**（来源：tencent-live-moderation.yml + 已有PRD API-AUDIT-001）：
- 事件类型315：音频审核事件通知（含hit_flag/score/label/suggestion/asr_text等核心字段）
- 智能擦除回调：擦除执行结果通知（API-AUDIT-005）
- 回调全量接收规则（BR-AUDIT-005）：全量接收+全量存储（含原始JSON），不截断不筛选

**关键约束**：
- 审核模板绑定后5-10分钟生效
- 绑定/修改/解绑仅影响新推流，不影响正在进行的流
- 默认仅返回不合规结果
- 音频审核仅支持中文音频
- 智能擦除依赖音频文字识别配置
- 智能擦除与字幕功能互斥
- 首次使用智能擦除需授权MPS

### 4.4 技术约束清单

- **签名验证**：回调需callback_key签名验证（sign=MD5(key+t)）
- **幂等性**：截图规则按DomainName+AppName+StreamName唯一
- **生效延迟**：配置变更后5-10分钟生效，仅影响新推流
- **存储依赖**：不合规截图/音频需存储到COS存储桶
- **互斥约束**：智能擦除与字幕功能互斥
- **回放擦音时机**（BR-AUDIT-004）：回放文件生成后立即擦音，擦音完成后才开放观看
- **回调全量接收**（BR-AUDIT-005）：全量接收+全量存储（含原始JSON）

### 4.5 异常场景清单

| 错误场景 | 处理建议 |
|----------|----------|
| COS存储桶不可写 | 审核证据丢失，需告警+重试机制 |
| 回调URL不可达 | 腾讯云自动重试3次 |
| 回调数据解析失败 | 存储原始JSON+标记解析异常 |
| AMS API调用失败 | 重试3次→仍失败标记擦音异常+通知运营 |
| 擦音处理超时（30分钟） | 标记超时+通知运营手动处理 |
| 替换回放文件失败 | 保留原始文件+标记异常+通知运营 |
| 智能擦除授权过期 | MPS权限失效，擦除功能降级为仅审核不擦除 |
| 处置超时（30秒未操作） | 系统自动记录+告警升级通知 |

## 九、决策冻结

以下决策已锁定（v1.1.0，整合补充资料后冻结）：

1. **V1/V2/V3三版路线图**——已有PRD验证可行的分阶段策略
2. **集成腾讯云CSS（实时）+AMS（回放）**作为底层AI审核能力（不自建）
3. **四层架构**：接入层 / 审核层 / 擦除层 / 管控层
4. **双主线流程**：实时审核线（CSS回调驱动）+ 回放审核线（AMS API驱动）
5. **实时擦音**由CSS智能擦除自动执行（静音/蜂鸣声可配置）
6. **回放擦音**由AMS API自动执行，擦音完成后才开放观看（不开放未擦音版本）
7. **6类不可降级规则**：涉黄/涉暴/公共安全/社会安全/违法乱纪/广告法
8. **生效词库并集**：平台不可降级∪平台基础∪租户扩展∪租户个性化
9. **处置渐进式**：L4记录→L3警告→L2断流→L1断流+封禁（可加严不可放宽）
