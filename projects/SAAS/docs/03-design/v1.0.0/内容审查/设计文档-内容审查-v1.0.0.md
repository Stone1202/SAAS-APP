## 1. 交互原则

### 1.1 三终端设计策略

| 终端 | 角色 | 密度 | 栅格 | 设计语言 | 核心交互特征 |
|---|---|---|---|---|---|
| PC-运营后台 | 平台运营 | 高密度 | 24列（1600px+基准） | Ant Design 数据管理型 | 表格集约+开关控制+批量操作 |
| PC-租户后台 | 租户运营 | 中高密度 | 24列（1440px基准） | Ant Design 操作型 | 侧滑面板+实时列表+快速处置 |
| H5-观众端 | APP观众 | 低密度 | 6列（375px基准） | 自然触感+轻量化 | 信息上浮+全屏沉浸+手势友好 |

### 1.2 核心交互原则

| # | 原则 | 说明 | 适用终端 |
|---|---|---|---|
| IP1 | **渐进式揭露** | 先展示概要，展开后展示详情；违规告警先展示级别，点击展开完整证据 | 全部 |
| IP2 | **行动召唤** | 处置按钮置底固定，告警级别视觉分层；断流按钮红色警告样式 | PC租户 |
| IP3 | **防呆设计** | 不可逆操作（断流）二次确认+倒计时确认 | PC全部 |
| IP4 | **实时感知** | 直播中控列表实时追加违规，告警级别徽标动态变色；场次结束后自动切换只读 | PC租户 |
| IP5 | **状态可见** | 处置状态清晰标注（已记录✅/已断流🔴/已忽略⚪/已超时⏰/已归档📦） | PC全部 |
| IP6 | **容错降级** | 擦音超时→锁定播放器→可重试；擦音失败→展示原片+警告→可重试 | PC租户 |
| IP7 | **仿真感知** | 仿真状态通过Store广播实时同步，不做假loading欺骗用户 | 全部 |
| IP8 | **移动优先** | 观众端H5：大触控区（≥44px）+ 滑动手势 + 底部操作栏固定 | H5 |
| IP9 | **擦音效果分级** | 静音模式=画面中心静音图标2-5s + 嘀声模式=画面中心音量图标+波形动画2-5s | H5 |
| IP10 | **关闭无痕** | 审查关闭后，所有审查入口消失，不残留任何审查UI痕迹 | 全部 |

### 1.3 交互粒度分级

| 级别 | 定义 | 示例 |
|---|---|---|
| L1-页面级 | 完整页面交互，含多区块联动 | 直播中控内容审查Tab（侧滑面板+实时列表+处置） |
| L2-区块级 | 页面内区块交互 | 场次信息区、违规列表区、处置操作区 |
| L3-组件级 | 表单/按钮/表格/搜索等组件交互 | 处置确认弹窗、对比播放面板 |
| L4-状态级 | 组件内状态变化 | 按钮置灰/加载动画/擦音进度条 |
