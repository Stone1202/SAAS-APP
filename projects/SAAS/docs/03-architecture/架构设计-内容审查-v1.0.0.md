# 架构设计文档 — 直播内容审查模块 V1.0.0

> **模块**：内容审查域（D16） | **版本**：V1.0.0 | **日期**：2026-07-22
> **设计依据**：16-内容审查域-PRD-v1.0.0.md + 设计文档-内容审查-v1.0.0.md
> **架构模式**：五维可插拔架构 V3.0.0（sim/real零修改切换）
> **技术栈**：Vue 3 + TypeScript + Vite + Pinia + Zod

---

## 1. 技术选型

| 维度 | 选型 | 说明 |
|---|---|---|
| 前端框架 | Vue 3 + Composition API | 复用SAAS平台现有技术栈 |
| 类型系统 | TypeScript 5.x | 全量类型安全 |
| 构建工具 | Vite 5.x | esbuild快速构建 |
| 状态管理 | Pinia | 复用SAAS平台现有Store模式 |

### 2.2 五维适配器映射

| 维度 | sim实现 | real实现 | 说明 |
|---|---|---|---|
| **data** | SimDataAdapter | RealDataAdapter | sim:模拟违规数据+IndexedDB存储; real:接收腾讯云回调+API请求 |
| **transport** | BroadcastChannelTransport | SSETransport | sim:跨标签页BroadcastChannel推送; real:Server-Sent Events实时推送 |
| **stream** | — | — | 内容审查不涉及直播流（由腾讯云处理） |
| **asset** | LocalAssetResolver | OssAssetResolver | sim:本地证据文件; real:腾讯云COS证据文件URL |
| **auth** | MockAuthProvider | JwtAuthProvider | sim:Mock认证; real:JWT认证 |

### 2.3 环境变量配置

```env
# .env.development (仿真模式)

# .env.production (真实模式)
```

## 7. 数据流设计

### 7.1 实时擦音数据流

```
腾讯云直播审核
    ↓ POST /api/audit/callback/review（全量JSON）
RealDataAdapter.receiveCallback()
    ↓ 解析+Zod校验
ContentReviewService.receiveCallback()
    ↓ 创建违规记录
ViolationService.save()
    ↓ IndexedDB/API存储
SSETransport.emit('violation')
    ↓ 实时推送
中控室内容审查Tab
    ↓ 展示违规告警
DisposalService.dispose()
    ↓ 运营处置
处置记录存储 + 状态更新
```

### 7.2 回放擦音数据流

```
直播域回放文件生成
    ↓ API-LIV-005回调
ReplayMuteService.triggerMute()
    ↓ 调用AMS API
腾讯云AMS音频审核
    ↓ 异步处理+擦音
POST /api/audit/callback/audio（擦音结果）
RealDataAdapter.receiveCallback()
    ↓ 解析+Zod校验
ReplayMuteService.handleMuteCallback()
    ↓ 替换回放文件
OssAssetResolver.replaceReplayFile()
    ↓ 更新回放文件
开放回放观看（擦音后版本）
```

### 7.3 词库同步数据流

```
平台运营/租户管理员修改词库
    ↓
KeywordLibraryService.add/edit()
    ↓ 本地存储
KeywordLibraryService.mergeEffectiveLib()
    ↓ 合并生效词库
SyncService.syncToTencent()
    ↓ 调用腾讯云API
腾讯云更新自定义敏感词库
    ↓ 同步完成
更新last_synced_at
```
