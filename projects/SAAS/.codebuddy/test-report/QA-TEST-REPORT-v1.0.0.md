### UC-AUDIT-003：回放擦音+人工核对

**页面**: `/tenant/live/:streamId/replay`  
**截图**: `uc003-replay-verify.png`

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 页面加载 | ✅ | 播放器区域、擦音任务进度、违规记录列表正确渲染 |
| 路由参数传递 | ✅ | `streamId` 正确从路由参数读取 |
| 违规时间轴标记 | ✅ | 播放器进度条上显示违规标记点 |
| 擦音前后对比 | ✅ | 左侧原始音频 / 右侧擦音后效果面板 |
| 发布状态标签 | ✅ | 显示"待核对" |
| ⚠️ 发布按钮可用性 | ❌ | 仪表盘显示"已完成擦音 待核对"，但回放页显示"擦音处理中 5/8" |

**Bug UC003-001**: 回放详情页不读取仪表盘 Store 中该 stream 的实际状态（`replayTask.task_status`），始终使用页面级 `muteTasks = { total: 8, completed: 5 }` 硬编码初始值，导致："核对并发布"从仪表盘点击进入后不可操作。需修复：页面 `onMounted` 时从 Store 读取该 stream 的回放任务进度。

## 缺陷清单

| 编号 | 归属 UC | 严重度 | 描述 |

| **BUG-001** | UC-AUDIT-003 | 🟡 P1 | 回放详情页不从 Store 读取 stream 级 replayTask 状态，使用硬编码进度 5/8，导致从仪表盘"核对并发布"进入后按钮不可见 |

## 测试结论

**整体评估**: 功能基本完整，核心链路（审查开关 → 中控违规处置 → 断流 → 仪表盘入口）流程通过。1 个 P1 缺陷需要修复后方可进入验收。

**建议**: 
1. 修复 BUG-001（回放页 Store 数据读取）
2. 优化 UX-001（按钮提示文字按级别区分）
3. 修复后回归验证 UC-AUDIT-003
