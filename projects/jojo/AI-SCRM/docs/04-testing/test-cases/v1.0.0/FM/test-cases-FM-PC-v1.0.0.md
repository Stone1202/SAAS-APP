# 测试用例 — 跟进管理+数据看板+系统设置（FM+DB+SS）× PC

> 关联FN：FN-FM-PC-001~004, FN-DB-PC-001~002, FN-SS-\* | PRD v1.0.1

## FM（跟进管理）

### TC-FM-PC-001：待办中心列表
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-FM-PC-001
- **步骤**：
  1. 进入待办中心 → 查看列表（标题/客户/优先级/截止时间/状态/来源）
  2. 按状态筛选「待处理」「已完成」
  3. 按优先级排序
  4. 标记某条为「完成」→ 确认
- **预期**：待办CRUD正常，优先级颜色标识正确

### TC-FM-PC-002：待办去重合并
- **优先级**：P1 | **类型**：功能用例 | **关联FN**：FN-FM-PC-001 | **关联BR**：BR-FM-001
- **前置条件**：同客户「张三」+同类型「跟进」+同日期 → 2条待办
- **步骤**：查看待办列表
- **预期**：合并为1条，显示「×2」合计标记

### TC-FM-PC-003：跟近日历
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-FM-PC-002
- **步骤**：
  1. 进入跟近日历 → 默认周视图
  2. 点击日期 → 查看当天待办列表
  3. 切换到月视图 → 验证日期上标记任务数量
- **预期**：日历视图交互正确，时间准确

### TC-FM-PC-004：客户360视图
- **优先级**：P1 | **类型**：功能用例 | **关联FN**：FN-FM-PC-003
- **步骤**：
  1. 客户详情 → 「360视图」Tab
  2. 验证7面板：基本信息/标签画像(AI摘要)/沟通历史/交易/跟进/情绪/意向演变
- **预期**：AI画像摘要内容合理，图表数据正确

### TC-FM-PC-005：客户分群管理
- **优先级**：P1 | **类型**：功能用例 | **关联FN**：FN-FM-PC-004
- **步骤**：
  1. 进入分群管理 → 查看已有分群
  2. 新建条件分群「高意向未成交」→ 条件：意向=高意向 AND 成交=否
  3. 保存 → 查看分群成员列表
- **预期**：条件筛选正确，成员列表实时反映

### TC-FM-PC-006：AI生成的跟进24h自动确认
- **优先级**：P1 | **类型**：流程用例 | **关联FN**：FN-FM-PC-001 | **关联BR**：BR-FM-003
- **前置条件**：AI生成跟进任务24小时未被处理
- **步骤**：系统定时任务触发
- **预期**：任务自动标记为「完成」，来源标注「AUTO_CONFIRM」
