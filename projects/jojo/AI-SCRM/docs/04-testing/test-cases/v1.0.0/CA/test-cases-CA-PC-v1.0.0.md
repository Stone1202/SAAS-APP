# 测试用例 — AI沟通辅助（CA）× PC

> 关联FN：FN-CA-PC-001~005 | 关联BR：BR-CA-001~007 | PRD v1.0.1

## 功能用例

### TC-CA-PC-001：实时话术推荐
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CA-PC-001 | **关联BR**：BR-CA-001
- **前置条件**：专业版租户，企微聊天窗口，≥3条对话上下文
- **步骤**：
  1. 客户发送「你们这个产品价格太贵了」
  2. 观察AI面板 → 推荐话术刷新
  3. 点击「采纳」→ 话术填入输入框
  4. 编辑后发送
- **预期**：推荐话术与客户内容上下文相关，采纳后方可发送

### TC-CA-PC-002：话术去重
- **优先级**：P1 | **类型**：功能用例 | **关联FN**：FN-CA-PC-001 | **关联BR**：BR-CA-002
- **前置条件**：话术A已推荐但未被采纳
- **步骤**：客户继续发送类似内容
- **预期**：新推荐列表中不重复出现话术A

### TC-CA-PC-003：实时情绪监控—正常
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CA-PC-002
- **步骤**：
  1. 客户发送「好的，我考虑一下」→ 情绪=中性
  2. 客户发送「好的，就这个方案」→ 情绪=积极
  3. 观察情绪指示器变色
- **预期**：情绪标签实时更新（中性→积极），指示器颜色对应

### TC-CA-PC-004：负面情绪告警
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CA-PC-002 | **关联BR**：BR-CA-003
- **步骤**：
  1. 客户连续发送3条负面消息：「太贵了」「不行」「我再看看吧」
  2. 观察弹窗告警
- **预期**：弹窗「客户情绪持续负面」+ 推荐安抚话术列表

### TC-CA-PC-005：意图识别+商品推荐
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CA-PC-003
- **前置条件**：AI检测到购买意向（置信度>0.7）
- **步骤**：
  1. 客户发送「我需要一款防晒产品」
  2. AI识别意图=购买、品类=美妆防晒
  3. AI推荐3款防晒商品（名称/价格/描述）
  4. 点击「一键发送」→ 商品卡片发送到聊天
- **预期**：推荐商品与意图匹配，一键发送格式正确

### TC-CA-PC-006：话术库管理
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CA-PC-004
- **步骤**：
  1. 进入话术库 → 查看分类列表
  2. 新建话术「问候语」分类 → 添加话术
  3. 编辑话术内容 → 保存
  4. 停用某话术 → 验证AI不再推荐
- **预期**：话术CRUD正常

### TC-CA-PC-007：沟通后自动总结
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CA-PC-005 | **关联BR**：BR-CA-005
- **前置条件**：沟通结束>30秒，专业版+
- **步骤**：
  1. 系统自动触发AI处理
  2. 展示：AI总结、质检评分、画像更新建议、跟进任务建议
  3. 逐项确认/修改
  4. 点击「确认全部」
- **预期**：4项全部确认后写入数据，待办自动创建

### TC-CA-PC-008：AI处理超时降级
- **优先级**：P1 | **类型**：异常用例 | **关联FN**：FN-CA-PC-005 | **关联BR**：BR-CA-004
- **步骤**：模拟Coze API超时
- **预期**：5秒超时后降级为「AI处理超时，请稍后重试」或本地规则引擎

## 流程用例

### TC-CA-PC-009：完整AI辅助闭环
- **优先级**：P0 | **类型**：流程用例 | **关联FN**：FN-CA-PC-001~005
- **步骤**：
  1. 发起企微聊天 → AI面板加载
  2. 对话3轮 → 话术推荐→采纳→发送
  3. 客户负面情绪3次 → 告警+安抚话术
  4. 客户表达购买意向 → 意图识别+商品推荐→一键发送
  5. 沟通结束 → AI总结/质检/画像/跟进4项确认
- **预期**：全链路AI能力无间断，数据一致可追溯

### TC-CA-PC-010：基础版无AI能力
- **优先级**：P0 | **类型**：边界用例 | **关联FN**：FN-CA-PC-001~005
- **前置条件**：基础版租户
- **步骤**：进入企微聊天 → 发起沟通 → 结束沟通
- **预期**：无AI面板、无自动处理、无AI总结、无质检评分

### TC-CA-PC-011：AI总结确认后不可回退
- **优先级**：P1 | **类型**：流程用例 | **关联FN**：FN-CA-PC-005 | **关联BR**：BR-CA-005
- **步骤**：
  1. 沟通结束 → AI处理 → 用户确认→ 保存
  2. 再次进入该记录 → 尝试修改AI结果
- **预期**：已确认的AI结果不可修改（只能追加备注）

### TC-CA-PC-012：质检不合格自动复审
- **优先级**：P1 | **类型**：功能用例 | **关联FN**：FN-CA-PC-005 | **关联BR**：BR-CA-006~007
- **前置条件**：AI质检评分=55分（<60不合格）
- **步骤**：沟通结束 → AI处理自动质检
- **预期**：
  - 评分55 → 标记「不合格」
  - 自动生成主管待复审任务
  - 主管可查看详细评分项（5维各几分）

### TC-CA-PC-013：话术采纳率统计
- **优先级**：P2 | **类型**：功能用例 | **关联FN**：FN-CA-PC-004
- **步骤**：查看话术列表 → 每句话术显示采纳次数/推荐次数/采纳率
- **预期**：统计数据准确，与沟通记录可溯源

### TC-CA-PC-014：双意图识别并发
- **优先级**：P2 | **类型**：边界用例 | **关联FN**：FN-CA-PC-003
- **步骤**：客户消息同时包含「购买意向」+「异议表达」
- **预期**：双意图同时识别，商品推荐+异议应对话术同时展示
