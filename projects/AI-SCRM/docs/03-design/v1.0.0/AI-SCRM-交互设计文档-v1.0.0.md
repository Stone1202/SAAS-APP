## 1. 交互原则

### 1.1 导航模式

| 系统 | 导航类型 | 方式 | 说明 |
|------|----------|------|------|
| 租户后台 | 侧边栏 + 顶部工具栏 | 一级菜单在左侧固定侧边栏（可折叠），二级菜单展开在侧边栏内 | 适配B端多模块场景，侧边栏宽度240px（展开）/ 64px（折叠） |
| 运营后台 | 侧边栏 + 顶部工具栏 | 同上 | 与租户后台保持一致体验 |

**面包屑**：所有二级及以上页面显示面包屑导航（`首页 > 模块 > 当前页`），点击可跳转。

### 1.2 表单交互模式

| 场景 | 校验时机 | 提交方式 | 反馈 |
|------|----------|----------|------|
| 简单表单（<5字段） | 失焦 + 提交 | 弹窗内提交，成功关闭弹窗 | Toast提示 + 列表刷新 |
| 复杂表单（≥5字段） | 失焦 + 提交 | 独立页面，提交后跳转 | 页面内成功状态展示 |
| 搜索筛选 | 实时（输入框300ms防抖） | 自动触发 | 列表实时刷新 + 结果计数 |

**批量操作模式**：列表支持勾选行 → 工具栏出现批量操作按钮（批量删除/批量导出等）→ 二次确认弹窗。

### 1.3 列表操作模式

| 操作方式 | 场景 | 交互 |
|----------|------|------|
| 行内操作（≤2个） | 常用快捷操作 | 列表最后一列显示操作按钮（文字按钮，每行≤2个） |
| 行内操作（>2个） | 多个操作 | 列表最后一列显示「更多」下拉按钮 → 点击展开菜单 |
| 行点击 | 查看详情 | 点击行任意位置（除操作列）→ 跳转详情页 |
| 表头排序 | 排序 | 点击列标题 → 切换排序（正序/倒序/取消）→ 箭头图标反馈当前排序方向 |

**虚拟滚动**：列表数据量>200条时启用虚拟滚动。

### 1.4 详情展示模式

| 模式 | 适用场景 | 布局 |
|------|----------|------|
| 信息面板 | 客户详情、租户详情 | Tab切换不同维度信息（Tab页签在顶部） |
| 侧边面板 | AI辅助面板、客户画像 | 右侧固定侧边面板，宽度360px |
| 全页展示 | 沟通记录详情 | 全页面铺开 |

### 1.5 弹窗/抽屉模式

| 控件 | 宽度 | 适用场景 | 关闭行为 |
|------|------|----------|----------|
| 模态弹窗（Modal） | 480-640px | 简单表单、确认操作 | 点遮罩/✕/ESC关闭，有dirty数据时二次确认 |
| 宽弹窗 | 720-960px | 复杂表单（≥5个字段）、详情编辑 | 同上 |
| 抽屉（Drawer） | 520-680px | 详情侧边面板、筛选面板 | 同上 |
| 确认弹窗 | 420px | 删除确认、状态变更确认 | 仅按钮关闭（防止误操作） |

### 1.6 反馈策略

| 反馈类型 | 位置 | 持续时间 | 场景 |
|----------|------|----------|------|
| Toast 成功提示 | 页面顶部居中 | 3秒自动消失 | 操作成功（新增/编辑/删除/保存） |
| Toast 错误提示 | 页面顶部居中 | 5秒自动消失 + 手动关闭 | 操作失败 |
| Notification 通知 | 右上角弹出 | 5秒或手动关闭 | 系统通知、预警提醒 |
| Tooltip 提示 | 悬停元素上方 | 悬停期间显示 | 操作说明、字段解释 |
| Confirm 确认弹窗 | 居中模态 | 用户操作后关闭 | 不可逆操作 |
| 内联错误提示 | 输入框下方 | 修复后消失 | 表单校验错误 |
