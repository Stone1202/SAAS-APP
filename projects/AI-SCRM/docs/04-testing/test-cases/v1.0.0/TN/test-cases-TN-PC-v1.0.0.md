# 测试用例 — 租户管理（TN）× PC

> 关联FN：FN-TN-PC-001~002 | 关联BR：BR-TN-001~003 | PRD v1.0.1

## 功能用例

### TC-TN-PC-001：租户列表与搜索
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-TN-PC-001
- **步骤**：进入租户管理 → 查看列表（名称/行业/版本/状态/健康度/到期时间）→ 搜索「测试租户」
- **预期**：列表20条/页，搜索精准

### TC-TN-PC-002：租户状态流转
- **优先级**：P0 | **类型**：流程用例 | **关联FN**：FN-TN-PC-001 | **关联BR**：BR-TN-001
- **步骤**：
  1. 创建租户 → PENDING
  2. 审核通过 → TRIAL（14天试用）
  3. 订阅付费 → ACTIVE
  4. 到期未续费 → GRACE（7天宽限期）
  5. 宽限期过 → SUSPENDED（功能冻结）
  6. 30天未处理 → CLOSED（数据归档）
- **预期**：每次状态变更记录时间戳+操作人，事件通知租户管理员

### TC-TN-PC-003：租户审核通过
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-TN-PC-001
- **前置条件**：租户状态=PENDING
- **步骤**：点击「审核通过」→ 确认
- **预期**：状态→TRIAL，trial_start设为当前时间，trial_end=trial_start+14天

### TC-TN-PC-004：租户健康度评分
- **优先级**：P1 | **类型**：功能用例 | **关联FN**：FN-TN-PC-001 | **关联BR**：BR-TN-003
- **前置条件**：租户已活跃运营15天
- **步骤**：查看租户详情 → 健康度评分
- **预期**：评分计算：登录频率(0.2)+功能深度(0.25)+客户活跃(0.25)+续费状态(0.2)+AI使用率(0.1)，范围0-100

## 流程用例

### TC-TN-PC-005：续费提醒流程
- **优先级**：P1 | **类型**：流程用例 | **关联FN**：FN-TN-PC-001 | **关联BR**：BR-TN-002
- **前置条件**：租户ACTIVE，距到期7天
- **步骤**：系统自动触发到期提醒
- **预期**：到期前7天/3天/1天分别发送续费提醒（企微消息+系统通知）

### TC-TN-PC-006：租户版本升级
- **优先级**：P1 | **类型**：流程用例 | **关联FN**：FN-TN-PC-002
- **前置条件**：租户当前基础版
- **步骤**：运营端 → 租户详情 → 升级到专业版 → 选择新套餐 → 确认
- **预期**：版本切换立即生效，AI功能解锁，订阅订单按比例计算差额

## 边界/异常

### TC-TN-PC-007：租户名称重复
- **优先级**：P1 | **类型**：边界用例 | **关联FN**：FN-TN-PC-001
- **步骤**：创建租户 → 使用已存在的名称
- **预期**：提示「租户名称已存在」

### TC-TN-PC-008：无效状态流转
- **优先级**：P1 | **类型**：异常用例 | **关联FN**：FN-TN-PC-001
- **步骤**：已CLOSED的租户 → 尝试审核通过
- **预期**：提示「该租户已关闭，无法操作」

### TC-TN-PC-009：宽限期后自动挂起
- **优先级**：P0 | **类型**：流程用例 | **关联FN**：FN-TN-PC-001 | **关联BR**：BR-TN-001
- **前置条件**：租户GRACE状态7天
- **步骤**：系统定时任务检测
- **预期**：状态自动→SUSPENDED，功能全部冻结，只读登录

### TC-TN-PC-010：租户搜索无结果
- **优先级**：P2 | **类型**：边界用例 | **关联FN**：FN-TN-PC-001
- **步骤**：搜索「不存在的租户xyz」
- **预期**：显示「暂无数据」空状态
