# 测试用例 — 统一沟通（UC）× PC

> 关联FN：FN-UC-PC-001~002 | 关联BR：BR-UC-001~003 | PRD v1.0.1

## 功能用例

### TC-UC-PC-001：发起企微沟通
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-UC-PC-001 | **关联BR**：BR-UC-002
- **前置条件**：专业版租户，企微已授权，员工已绑定
- **步骤**：
  1. 客户详情 → 「发起沟通」→ 默认企微渠道
  2. 聊天窗口加载客户历史消息（最近20条）
  3. 客户画像侧边栏加载（基本信息+标签+沟通摘要）
  4. 输入「你好，关于上次的咨询…」→ 发送
- **预期**：消息发送成功，聊天窗口实时展示，沟通记录创建

### TC-UC-PC-002：多渠道切换
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-UC-PC-001
- **步骤**：
  1. 企微聊天 → 切换到电话Tab → 显示拨号盘
  2. 切换到短信Tab → 显示模板选择+编辑区
  3. 切换到邮件Tab → 显示邮件编辑器
- **预期**：每次切换保留对应渠道的草稿内容

### TC-UC-PC-003：沟通记录列表与筛选
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-UC-PC-002
- **步骤**：
  1. 进入沟通记录页 → 列表按时间倒序
  2. 按沟通方式筛选「企微」→ 验证
  3. 按客户筛选「张三」→ 验证
  4. 点击某条记录 → 进入详情
- **预期**：筛选精准，跳转正确

### TC-UC-PC-004：沟通详情展示
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-UC-PC-002
- **前置条件**：存在已结束的沟通记录
- **步骤**：点击沟通记录 → 查看详情
- **预期**：显示完整对话/通话记录、AI总结卡片（专业版+）、质检评分（专业版+）、画像更新记录（专业版+）

## 边界/异常

### TC-UC-PC-005：企微渠道不可用
- **优先级**：P1 | **类型**：异常用例 | **关联FN**：FN-UC-PC-001
- **步骤**：企微取消授权后发起沟通
- **预期**：显示「渠道暂不可用」+ 提示其他可用渠道

### TC-UC-PC-006：客户无手机号
- **优先级**：P1 | **类型**：异常用例 | **关联FN**：FN-UC-PC-001
- **步骤**：切换到电话/短信 → 客户无手机号
- **预期**：提示「请先完善客户手机号」

### TC-UC-PC-007：短信余额不足
- **优先级**：P2 | **类型**：异常用例 | **关联FN**：FN-UC-PC-001 | **关联BR**：BR-UC-003
- **步骤**：短信余额=0时发送短信
- **预期**：提示「短信余额不足，请联系管理员充值」

### TC-UC-PC-008：长时间沟通后结束
- **优先级**：P1 | **类型**：流程用例 | **关联FN**：FN-UC-PC-001~002 | **关联BR**：BR-UC-001
- **步骤**：发起沟通 → 持续聊天30分钟 → 结束沟通
- **预期**：沟通记录状态从ACTIVE→ENDED→PROCESSING→COMPLETED，AI后处理自动触发

### TC-UC-PC-009：基础版不显示AI功能
- **优先级**：P1 | **类型**：边界用例 | **关联FN**：FN-UC-PC-001~002
- **前置条件**：基础版租户
- **步骤**：进入企微聊天窗口
- **预期**：无AI辅助面板，沟通记录详情无AI总结/质检/画像更新

### TC-UC-PC-010：空消息拦截
- **优先级**：P2 | **类型**：边界用例 | **关联FN**：FN-UC-PC-001
- **步骤**：不输入内容 → 点击发送
- **预期**：按钮置灰（disabled），不可发送空消息

### TC-UC-PC-011：网络中断恢复
- **优先级**：P2 | **类型**：异常用例 | **关联FN**：FN-UC-PC-001
- **步骤**：聊天中网络断开 → 5秒后恢复 → 尝试重新发送
- **预期**：显示离线提示 → 重连后消息自动补发

### TC-UC-PC-012：并发沟通
- **优先级**：P2 | **类型**：边界用例 | **关联FN**：FN-UC-PC-001
- **步骤**：同时打开3个客户的沟通窗口（多Tab）
- **预期**：消息互不串扰，各窗口独立
