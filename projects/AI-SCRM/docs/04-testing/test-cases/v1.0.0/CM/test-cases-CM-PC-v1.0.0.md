# 测试用例 — 客户管理（CM）× PC

> 关联FN：FN-CM-PC-001~004 | 关联BR：BR-CM-001~004 | PRD v1.0.1

## 功能用例

### TC-CM-PC-001：正常创建客户
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CM-PC-002
- **前置条件**：用户已登录，租户客户数<上限
- **步骤**：
  1. 进入客户列表 → 点击「新增客户」
  2. 填写：姓名字段、手机号、公司（可选）、标签（可选）、来源（可选）
  3. 点击「保存」
- **预期**：客户创建成功，列表刷新，新客户高亮显示
- **数据校验**：ENT-TNT-001（Customer）字段完整

### TC-CM-PC-002：手机号重复合并
- **优先级**：P0 | **类型**：异常流程 | **关联FN**：FN-CM-PC-002 | **关联BR**：BR-CM-002
- **前置条件**：系统已存在手机号138****1234的客户
- **步骤**：新增客户 → 输入同名手机号 → 点击保存
- **预期**：弹窗「该手机号已关联客户[张*]，是否合并？」

### TC-CM-PC-003：体验版客户数上限阻断
- **优先级**：P1 | **类型**：边界用例 | **关联FN**：FN-CM-PC-002 | **关联BR**：BR-CM-004
- **前置条件**：体验版租户，当前客户数=200
- **步骤**：尝试新增客户
- **预期**：提示「已达上限，请升级版本」，客户不创建

### TC-CM-PC-004：客户列表分页与筛选
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CM-PC-001
- **前置条件**：系统存在≥20条客户数据
- **步骤**：
  1. 进入客户列表 → 验证默认分页20条
  2. 点击下一页 → 验证数据正确
  3. 搜索「张三」→ 验证搜索结果
  4. 按标签筛选「VIP」→ 验证过滤结果
  5. 按来源筛选「线上推广」→ 验证过滤结果
- **预期**：分页正确、搜索精准、多条件筛选结果正确

### TC-CM-PC-005：标签管理增删改查
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CM-PC-004 | **关联BR**：BR-CM-003
- **前置条件**：用户有标签管理权限
- **步骤**：
  1. 进入标签管理 → 查看已有标签列表
  2. 新建标签组「行业标签」+ 标签「金融」
  3. 编辑标签颜色 → 保存
  4. 停用标签 → 验证关联客户的标签显示为灰色
- **预期**：标签CRUD正常，关联客户标签同步更新

### TC-CM-PC-006：标签关联客户
- **优先级**：P0 | **类型**：功能用例 | **关联FN**：FN-CM-PC-004
- **前置条件**：客户「张三」存在于列表中
- **步骤**：
  1. 客户列表 → 勾选「张三」
  2. 批量操作 → 打标签 → 选择「VIP」
  3. 确认
  4. 查看「张三」详情 → 验证标签已有「VIP」
- **预期**：标签正确关联，详情页显示正确

## 流程用例

### TC-CM-PC-007：客户完整生命周期
- **优先级**：P0 | **类型**：流程用例 | **关联FN**：FN-CM-PC-001~004
- **步骤**：
  1. 新增客户「李四」→ 标签「新客」
  2. 搜索「李四」→ 点击进入详情
  3. 编辑公司信息 → 保存
  4. 打标签「潜在大客户」→ 验证标签列表更新
  5. 删除客户 → 确认 → 验证列表不再出现
- **预期**：全流程数据一致性

### TC-CM-PC-008：批量导入客户
- **优先级**：P1 | **类型**：流程用例 | **关联FN**：FN-CM-PC-001
- **步骤**：
  1. 客户列表 → 点击「导入」
  2. 下载模板 → 填充50条客户数据
  3. 上传文件 → 系统校验 → 确认导入
- **预期**：
  - 50条正确导入
  - 重复手机号行跳过并提示
  - 超出版本上限部分阻断

## 边界/异常用例

### TC-CM-PC-013：同步删除客户数据一致性
