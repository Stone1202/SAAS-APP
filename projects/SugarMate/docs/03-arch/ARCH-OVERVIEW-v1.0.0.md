## 四、架构设计决策矩阵

| ADR | 决策 | 关键约束 |
|:---|------|----------|
| ADR-001 | 4物理终端(MP/APP/LIVE/PC) | APP内4角色视图·共享代码 |
| ADR-002 | APP单代码库+路由守卫 | 禁止角色视图独立建库 |
| ADR-003 | LIVE端独立APP | 腾讯云SDK+DeepLink互通 |
| ADR-004 | PC后台同源多端 | /admin/ops/ + /admin/merchant/ |
| ADR-005 | 管理端(PC)≠经营端(APP)·独立API | 防止权限泄漏 |
| ADR-006 | uni-app + LIVE原生 + PC React | 跨端不强求统一 |
| ADR-007 | OpenAPI 3.0自动文档 | 前后端契约对齐 |
| ADR-008 | JSON日志 + APM + Sentry | request_id全链路 |
| ADR-009 | Docker + K8s + GitOps | 10微服务独立部署 |
| ADR-010 | Redis Cache-Aside | 缓存不可作为SQL Server的替代 |
| ADR-011 | APP离线·IndexedDB + Service Worker | MP降级Cache(10MB) |
| ADR-012 | AI辅助决策·12项全部经架构师确认 | AI不替代·但加速×5 |
