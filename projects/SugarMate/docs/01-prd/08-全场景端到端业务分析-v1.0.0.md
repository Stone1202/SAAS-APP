### 2.1 商品类型路由矩阵

| 商品类型 | 处方校验 | 注册证校验 | 冷链可适用 | 订单状态机 | 关键差异 |
|:------:|:------:|:------:|:------:|:------:|----------|
| **OTC** | ❌ | ❌ | ✅(部分) | SM-05 | 可直接下单，无处方卡点 |
| **RX** | ✅**强校验** | ❌ | ✅(胰岛素等) | SM-05 + SM-03 | 须关联有效处方 + 药房审方 |
| **DEVICE** | ❌ | ✅(III类) | ✅(部分器械) | SM-05 | III类器械须注册证 |
| **SUPPLEMENT** | ❌ | ❌(批准文号) | ❌ | SM-05 | 须批准文号 |
| **FOOD** | ❌ | ❌ | ✅(低GI/代餐) | SM-05 | 常规流程 |
| **DAILY** | ❌ | ❌ | ❌ | SM-05 | 常规流程 |
| **SERVICE** | ❌ | ❌ | ❌ | SM-16 | 独立服务订单流程 |

## 3. 四大主链路

```
┌────────────────────────────────────────────────────────────────┐

│  涉及状态机: SM-CON-01 问诊状态机                                 │

└────────────────────────────────────────────────────────────────┘

患者                         系统                         医生
 │                           │                            │
 │  ① 选择问诊方式            │                            │
 │  ├─ 图文问诊 9.9元         │                            │
 │  ├─ 语音问诊 19.9元        │                            │
 │  └─ 视频问诊 29.9元        │                            │
 │                           │                            │
 │  ② 描述症状+上传资料       │                            │
 │  (血糖记录/检验报告/图片)   │                            │
 │                           │                            │
 │  ③ 支付问诊费              │                            │
 │  ──────────────────────────►                            │
 │                           │  创建问诊会话               │
 │                           │  CON_STATUS: CREATED       │
 │                           │                            │
 │                           │  匹配医生 (平台分配/指定)    │
 │                           │  CON_STATUS: MATCHING      │
 │                           │  ──────────────────────────►│
 │                           │                            │ ④ 接诊

 │                           │                            │
 │ ⑤ 问诊对话                 │                            │ ⑤ 问诊对话
 │  ──────────────────────────►                            │
 │  ◄─ 医生追问症状/病史 ──── │  ◄──────────────────────────│
```

- 无处方 → 不触发 SM-03
- 无购药 → 不触发 SM-05
- 问诊费即时结算
- 48h 自动超时结束

```
┌──────────────────────────────────────────────────────────────────────┐
│  链路B: 问诊 → 开处方 → 患者下单 → 药房审方 → 配药发货 → 签收完成    │
│  涉及角色: 患者 → 医生 → 药剂师 → 药房                               │
```

**关键特征**:
- 跨3个状态机 (SM-CON-01 → SM-03 → SM-05)
- 跨4个角色 (患者/医生/药剂师/药房)
- 处方药订单必须关联有效处方 (硬约束)
- 药房审方是处方向交易流转的必要卡点
- 混合订单 (RX+OTC+DAILY) 按商品类型可独立追踪

### 3.3b 链路C-冷链: OTC/器械(冷链商品) 直接购药

若链C中的商品含冷链标记 → 在 SHIPPED 阶段额外触发:

```
SHIPPED
 │
 ├─ 创建 ColdChainShipment (绑定IoT设备)
 ├─ IoT MQTT 温度上报 (2~8°C 阈值)
 │
 ├─ [正常] 温度全程合格 → DELIVERED
 │
 └─ [异常] 温度超阈值 → COLD_CHAIN_EXCEPTION
     │
     ├─ 补发 ≤2次 → 重新 SHIPPED
     └─ 补发超限 → REFUNDING → REFUNDED
```

| AWAITING_SHIP | 药房发货 | SHIPPED | 药房 | 备货完成+物流单号 | 推送配送信息+冷链监控 |
| SHIPPED | 患者签收 | DELIVERED | 患者 | 收到包裹 | 7天倒计时开始 |
| SHIPPED | 冷链异常 | COLD_CHAIN_EXCEPTION | [IoT自动] | 温控超限 | 告警+补发判定 |
| COLD_CHAIN_EXCEPTION | 补发(≤2次) | SHIPPED | 药房 | resend_count<2 | resend_count++ |
| COLD_CHAIN_EXCEPTION | 补发超限(≥2) | REFUNDING | [系统自动] | resend_count≥max | 标记药房+强制退款 |
| DELIVERED | 7天到期 | COMPLETED | [系统自动] | 无售后纠纷 | 评价邀请+积分发放 |
| DELIVERED | 用户申请退款 | REFUNDING | 患者 | 退货原因 | 药房审核 |
| PAID~DELIVERED | 客服介入退款 | REFUNDING | 平台 | 纠纷裁决 | 按裁决执行 |
| REFUNDING | 退款到账 | REFUNDED | [系统自动] | 支付网关回调成功 | 通知+积分回退 |

### 10.1 冷链关键时间线

| 事件 | 时间要求 | 超时处理 |
|------|:------:|---------|
| 发货→设备激活 | 出库后≤5min | 标记延迟 |
| 温度异常检测 | 实时(QoS=2) | 连续3次丢包→标记异常 |
| 告警通知 | ≤15min | 升级平台运营 |
| 药房响应 | ≤30min | 自动触发补发 |
| 补发间隔 | ≤4h | 升级平台人工 |
| 全程运输时长 | ≤商品运输上限(通常48h) | 提前预警 |

### 10.2 三类冷链断链处理

| 商品类型 | 断链动作 | 典型药品/器械 |
|:------:|---------|------------|
| **COLD**(冷藏2-8°C) | DESTROY_ON_BREAK 断链即销毁 | 胰岛素、GLP-1受体激动剂 |
| **FROZEN**(冷冻-25~-15°C) | DESTROY_ON_BREAK 断链即销毁 | 部分生物制剂 |
| 部分器械 | REASSESS_ON_BREAK 断链后评估 | 血糖试纸(非必须全程冷链) |

## 15. 异常处理全景

```
                    异常分类 & 处理

         ┌───────────────┼───────────────┐
         │               │               │
    ┌────▼────┐    ┌─────▼─────┐    ┌───▼──────┐
    │患者侧    │    │  医生侧    │    │ 系统侧    │
    │异常      │    │  异常      │    │ 异常      │
    └────┬────┘    └─────┬─────┘    └───┬──────┘
         │               │               │
    ┌────┴────────────────┴───────────────┴────┐
    │                                            │
    │  问诊异常                                   │
    │  • 支付成功但未匹配到医生 → 退款+通知       │
    │  • 医生超时未接诊 → 重新匹配(max 3次)      │
    │  • 48h会话超时 → 自动结束+5G总结           │
    │  • Im消息投递失败 → 重试3次→降级短信       │
    │                                            │
    │  处方异常                                   │
    │  • CA签名失败 → 医生重试或临时线下签       │
    │  • 药物相互作用风险 → 硬阻断+提示医生      │
    │  • 处方过期 → 不可用于购药+通知患者        │
    │  • 药房审方拒绝 → 医生修改后重审           │
    │                                            │
    │  订单异常                                   │
    │  • 支付超时15min → 取消+库存释放           │
    │  • 支付成功但回调延迟 → 主动查询+补回调    │
    │  • RX校验失败 → 仅退款RX商品(CANCEL)       │
    │  • 库存不足 → 部分发货+缺货退款            │
    │                                            │
    │  冷链异常                                   │
    │  • 温度超标 → 告警→补发≤2→强制退款        │
    │  • IoT设备离线 → 告警→人工核查             │
    │  • 运输超时 → 预警→升级运营                │
    │  • 包裹丢失 → 补发→同步投诉渠道            │
    │                                            │
    │  服务异常                                   │
    │  • 48h无人接单 → 退款+通知                 │
    │  • 服务不满意→退回修改≤3→强制完结(50%)     │
    │  • 包月解约 → 按天结算退款                 │
    │  • 自动续费失败 → 3次重试→降级通知         │
    │                                            │
    │  支付异常                                   │
    │  • 易宝主通道不可用 → 自动切换微信备用      │
    │  • 分账失败 → 重试队列+异步补分账          │
    │  • 退款失败 → 人工处理+对账补偿            │
    │                                            │
    └────────────────────────────────────────────┘
```
