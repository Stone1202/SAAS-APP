## 一、全场景×五维闭环分析

> 以下 61 个场景按域组织，每个场景输出五维分析（角色/操作/信息/状态/异常），并在每个域末尾融入 PRD 深入细化的 FN 级决策与盲区审查结果。

### A. 小程序·获客引流域（MP）

#### S01 健康科普内容浏览
| 维度 | 内容 |
|------|------|
| 角色 | 未登录访客/微信用户 |
| 操作流 | 进入小程序→首页推荐流→点击文章→阅读→收藏/分享/[手动] |
| 信息流 | CMS内容库→推荐引擎→小程序前端；用户行为回传→行为分析 |
| 状态流 | 内容：草稿→审核→已发布→已下架；用户：匿名→浏览→关注 |
| 异常分支 | 内容加载失败降级到缓存、无网络展示离线文章、违规内容审核驳回 |

**PRD深入细化 FN 决策**：
- **Q1（内容来源）** → 自产+PGC+AI辅助生成，三级审核（编辑→医学审核→发布）【已确认：自产+PGC双轨】
- **Q2（推荐策略）** → 初期标签规则+热度，中期接入推荐算法【已确认：渐进式】
- **盲区—用户运营**：新用户冷启动内容推荐策略（基于问卷画像的首次推荐）
- **盲区—安全合规**：医疗科普免责声明与内容合规边界（不可替代医生诊断）

#### S02 糖尿病风险评估问卷
| 维度 | 内容 |
|------|------|
| 角色 | 微信用户 |
| 操作流 | 点击风险评估→逐题作答→提交→即时结果展示→引导关注/下载APP/[手动+系统自动] |
| 信息流 | 题库管理→评估引擎→风险等级计算→结果页；答题数据→用户画像初始化 |
| 状态流 | 问卷：进行中→已完成（可重新评估）；用户标签：无→风险等级[高/中/低] |
| 异常分支 | 中途退出保存进度、重复评估覆盖历史、题库版本升级兼容 |

**PRD深入细化 FN 决策**：
- **Q3（题库来源）** → 基于中国2型糖尿病防治指南+ADA标准设计【已确认】
- **Q4（结果策略）** → 高风险引导在线问诊、中风险引导健康计划、低风险引导关注【已确认】
- **盲区—法务合规**：风险评估免责声明（"本评估不能替代医疗诊断"）

#### S03 AI智能问答
| 维度 | 内容 |
|------|------|
| 角色 | 微信用户 |
| 操作流 | 输入问题→AI理解意图→检索知识库→生成回答→展示引用来源→满意度评价/[系统自动] |
| 信息流 | 用户问题→NLU→知识库检索(RAG)→LLM生成→回答+引用；满意度→模型优化反馈 |
| 状态流 | 问答：待回答→回答中→已回答→已评价 |

- **Q5（AI基座）** → 基于医学知识库RAG + 通用LLM，不自行训练医疗模型【已确认】
- **Q6（敏感拦截）** → 诊断/用药建议类问题强制重定向到「在线问诊」入口【已确认】
- **盲区—安全合规**：AI生成内容的医学准确性兜底机制（医学团队定期抽检+用户纠错反馈）

```
  小程序内容→风险评估→企微SCRM→APP问诊/购药/管理→社区→分享裂变→新用户

闭环2：问诊→处方→购药→用药→复诊
  线上问诊→电子处方→药房购药→用药管理→复诊提醒→再次问诊

闭环3：监测→分析→干预→效果评估
  CGM/BGM监测→数据分析→饮食/运动/用药建议→健康报告→方案调整

闭环4：内容→消费→互动→UGC
  PGC/专家内容→用户消费→社区互动→UGC产生→内容再生产

闭环5：商家入驻→商品上架→交易→结算→复购
  商家审核→商品管理→订单交易→财务结算→数据复盘→再次上架
```

## 三、全局状态机

### 3.1 核心实体状态机

**用户生命周期**：
```
匿名访问 → 已注册 → 已完善资料 → 活跃用户 → 付费会员 → 休眠 → 流失
                                                    ↓
                                          续费 ← 到期提醒
```

**问诊状态**：
```
待支付 → 已支付(待接诊) → 问诊中 → 已完成 → 已评价
                       ↓
                  超时未接诊 → 已退款
```

**处方状态**：
```
草稿 → 待签名 → 待审核 → 审核通过 → 已生效 → 已调剂 → 已完成
                      ↓
                 审核驳回 → 修改重提
```

**订单状态**：
```
待支付 → 已支付 → 待发货 → 已发货 → 运输中 → 已签收 → 已完成
                                               ↓
                                          拒收 → 退货中 → 已退款
```

**商家入驻状态**：
```
待提交 → 审核中 → 审核通过 → 已签约 → 已开店 → 运营中 → 暂停 → 关闭
              ↓
         审核驳回 → 重新提交
```

### 10.2 合规原则（糖友之家合规底线6条）

1. **互联网诊疗管理办法**：问诊须实名、处方须审核、精麻药品禁售
2. **药品网络销售监督管理办法**：处方药展示须实名后可见、药房须GSP认证
3. **医疗器械经营监督管理办法**：CGM属二类医疗器械，销售需备案
4. **个人信息保护法**：医疗健康数据为敏感个人信息，须单独同意
5. **广告法**：医疗广告须审批、健康科普不得含诊疗承诺
6. **HIPAA类比**：虽在中国运营，按HIPAA标准设计数据安全体系
