## 一、核心交易闭环

### 1.1 商品发布到上架

```
运营端品类管理（创建品类，含特殊资质）
  ↓
租户端商品管理：
  选择类目（认证范围内）→ 填写基本信息（名称/主图≤15张/视频≤1个）
  → 配置规格SKU（≤4种规格）→ 设置价格库存（采购价/售价/划线价/总库存）
  → 配置物流（快递/自提）→ 配置服务保障 → 填写商品介绍 → 保存
  ↓
商品状态：审核中 → 审核员审核
  ├─ 通过 → 在售中（APP端可见可下单）
  └─ 不通过 → 审核不通过（可编辑后重新提交）
```

**商品状态机**：审核中 →（通过）→ 在售中 →（下架）→ 已下架 →（上架）→ 在售中

### 1.2 正向交易流程（快递）

```
客户浏览商品 → 领券/红包 → 创建订单（待付款）
  ├─ 组合支付：实付=订单应收-优惠券-红包-积分抵现
  ├─ 优惠分摊：盈余追加法做SKU维度分摊
  └─ 优惠独立记录每种形式以便逆向退券
  ↓
支付（交易域）→ 支付回调（幂等）→ 更新订单待发货 + 库存扣减
  ↓
待发货 → 全部发货 → 已发货
  ↓
已发货 → 买家签收/超时7天自动确认 → 已完成 → 触发佣金结算（T+售后期）
```

### 1.3 正向交易流程（自提）

```
客户下单选择自提 → 支付 → 生成提货码（YXKSA+6位随机数）
  → 待自提 → 店员扫码核销 → 已完成
```

### 1.4 订单超时关闭

```
待付款 + 超时30分钟未付 → 已关闭（释放预占库存）
待付款 + 买家取消 → 已关闭
```

### 1.5 逆向交易流程（售后）

```
订单状态≥待发货时发起售后 → 订单进入售后中（操作挂起）
  ├─ 仅退款 → 退款审核
  ├─ 退货退款 → 寄回→验货→退款审核
  └─ 换货 → 寄回→寄出新商品
  ↓
售后完成/关闭 → 订单恢复原状态
  ↓
全部商品售后完成 → 订单已关闭
  ↓
退款触发多重回滚：支付单→已退款 + 佣金回滚 + 积分退还 + 库存回滚（退货退款）
```

### 1.6 交易资金流转

```
客户支付
  ├─ 普通模式：资金进入租户账户
  └─ 担保交易（待建）：资金锁定→确认收货→解冻→打款
  ↓
分账（T+售后期后触发）：
  ├─ 平台直连分账（待建）：资金进平台虚拟账户→按清分规则清分
  │   清分规则：按比例/按固定金额/按阶梯
  └─ 分账方：供应商/代理/门店
  ↓
佣金结算（分佣管理域）：按分佣政策计算佣金→佣金明细记录
```

**支付单状态机**：待支付→已支付/担保锁定→已解冻→已分账→（退款）→已退款

## 二、营销与客户闭环

### 2.1 营销活动→下单→退券闭环

```
营销管理创建活动（优惠券/抽奖/红包/观看奖励/支付有礼/积分）
  ↓
客户领取优惠 → 下单使用优惠（允许多种叠加，极端可选三种）
  ↓
退款时逆向退券（优惠金额独立记录每种形式）
```

### 2.2 客户管理闭环

```
客户注册/首次下单 → 成为客户
  → 标签管理（手动/自动打标签）
  → 会员等级（成长值累积→升级/保级/降级→权益变化）
  → 黑名单（禁止下单/登录）
  → 客户关系（上下级推荐关系）
  → 公海客户（无人跟进→可被分配）
```

### 2.3 营销→客户→订单联动

```
营销活动吸引→客户注册/下单→成为客户
  →消费累积成长值→等级提升→更多权益
  →下单使用优惠→优惠抵扣→实付减少
  →订单完成→触发分佣→佣金结算
  →客户退款→佣金回滚+积分退还+优惠退券
```

## 三、直播带货闭环

```
直播管理：主播注册/资质审核 → 创建直播计划 → 选择直播商品（来源=门店商品）
  ↓
开播 → 直播中：
  观众观看→观看奖励→主播讲解→观众点击购买→直播商品下单（标记场次+主播）
  ↓
直播结束 → 直播统计（观看/互动/转化数据）
  ↓
直播订单走正常交易流程（商品→订单→支付→发货→完成→分佣）
```

**直播关联**：
- 直播商品来源=门店商品集合（非租户整体商品）
- 直播订单标记直播来源（场次+主播）
- 观看奖励关联营销域
- 运营端AI提示词模板库供直播AI功能调用

---

## 四、门店运营闭环

```
门店管理（创建门店：名称/分组/店主/发货地址/售后地址）
  → 门店商品（同步在售商品，门店库存≤总库存）
  → 门店成员（分配员工）
  → 店员账户（支持扫码核销）
  ↓
门店运营：
  门店商品上架→APP端门店可购买
  →客户下单选择自提门店→生成提货码
  →店员扫码核销→完成自提订单
  →门店订单走正常交易流程
```

**门店关联**：
- 门店商品默认读取在售中状态商品
- 门店库存总和≤总库存
- 自提订单关联门店+店员核销
- 设置>设置自提（自提点管理）

## 五、供应链闭环

```
供应商管理（创建供应商：账户/收入MB/支出MB）
  → 供应商账户（钱包ID/商户号/商户Key/商户秘钥）
  → 商品绑定供应商
  → 采购价双向同步（租户改→同步供应商，供应商改→同步租户）
  → 采购价变更→触发财务域佣金重新计算
  → 供应商作为分账方之一参与分账清分
```

## 七、组织与权限闭环

```
租户订阅版本→获得应用权限（决定可见菜单）
  →组织管理（多级架构：成员/资质/主体/上下级）
  →设置>员工管理（员工关联组织）
  →设置>角色管理（角色分配功能权限）
  →员工分配角色→获得操作权限
  →门店成员关联员工→获得门店操作权限
  →数据权限：员工只看自己门店/组织的数据
```

## 八、运营管理闭环

### 8.1 租户生命周期

```
运营端租户管理（202个租户）
  →租户注册→账户管理（6种操作：资质/版本订购/合同/资源订购/虚拟账户/禁用）
  →租户订阅版本→获得应用权限+资源配额
  →版本到期提醒（剩余不足7天）→逾期无法营业
  →运营端可禁用租户→租户无法登录
```

### 8.2 版本-应用-资源管理

```
运营端产品管理：
  应用管理（创建应用+上架）→ 版本管理（关联应用+资源+发布）→ 资源管理（多规格配置）
  ↓
租户端版本市场→浏览订阅→获得应用权限+资源配额
  ↓
订购记录管理（606条，运营端应用管理查看）
```

### 8.3 全局配置

```
运营端系统配置（53项）：
  APP配置（热更新/版本下载/默认游客店）
  支付配置（fy充值/经销商充值审核）
  协议配置（业务/平台/页面选项）
  邀请码配置
  →全局生效（所有租户共用）
```

### 8.4 协议与行业

```
协议管理（多版本/按平台+业务分类）→租户注册/订阅时签署
行业管理（13个行业）→版本管理按行业细分（59个版本×13个行业）
品类管理（多级品类/特殊资质）→租户商品按品类分类
```
