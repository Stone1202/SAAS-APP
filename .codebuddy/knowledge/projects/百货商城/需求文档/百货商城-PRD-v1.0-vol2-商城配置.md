### 模块 D：业务流程

#### PG-商城配置-04：业务流程（辅助理解，无需开发）

**页面**：后台 → 商城配置 → 业务流程

**说明**：该页面仅供辅助理解业务流程，无需开发实现。用于在商城配置-业务流程中设置门店退货返厂平台审核的业务流程。

**门店退货返厂完整流程**（来源：版本描述.html）：

```
已支付商品
    → 申请退货退款
    → 是否同意退货退款？（由门店或平台任意一方进行审核）
        → 是 → 退货商品返还 → 是否收到用户退货商品？
            → 是 → 退款完成
            → 否 → （等待）
        → 否 → 退款完成

待返厂商品数据
    → 申请退货商品返厂
    → 是否同意返厂商品申请？
        → 是 → 填写返厂商品物流信息 → 等待收货 → 确认收货 → 完成退货商品返厂
        → 否 → （结束）
```

## 3. 业务规则（BR）

### BR-CONFIG-01：配置值编辑通用交互
**触发条件**：操作员点击"编辑配置值"
**行为**：弹出编辑配置值弹窗，显示配置名（只读）、配置值（可编辑）、描述（只读）；保存后生效并关闭弹窗，取消/X关闭弹窗不保存

### BR-CONFIG-02：小程序更多模块权限多选规则
**触发条件**：操作员编辑小程序更多模块权限配置值
**行为**：多选标签形式，选择的功能在小程序【更多】模块页面中显示，没选的不显示；默认全选：福利券商城、积分商城、收货地址、钱包、红包账户、账号设置

### BR-CONFIG-03：待收货入口显隐规则
**触发条件**：配置项"是否显示待收货订单状态"变更
**行为**：选"是"时小程序显示待收货订单状态和入口；选"否"时小程序不显示

### BR-CONFIG-04：退货地址默认门店规则
**触发条件**：配置项"自提订单退货地址是否默认为门店地址"为"是"
**行为**：自提订单退货地址默认为门店地址

### BR-CONFIG-05：退货物流填写规则
**触发条件**：配置项"自提订单退货是否需要填写物流信息"为"否"
**行为**：自提订单在申请退货退款时无需填写物流单号

### BR-CONFIG-06：默认地址数据来源
**触发条件**：设置默认地址
**行为**：下拉选择数据来源于"使用场景"为"退货地址"且"启用"状态为"启用"的地址记录

### BR-CONFIG-07：地址删除确认
**触发条件**：操作员点击删除地址
**行为**：弹出二次确认弹窗"是否确定删除该数据吗？"，确认后删除，取消则关闭弹窗

## 5. 验收标准

### 场景级 E2E

#### SC-CONFIG-01：交易配置 — 待收货状态显隐
**Give** 后台操作员在交易相关页面
**When** 将"是否显示待收货订单状态"配置值改为"否"并保存
**Then** 小程序端不显示待收货订单状态和相关入口

#### SC-CONFIG-02：地址配置 — 新增并设为默认
**Give** 操作员进入地址配置页面
**When** 新增一条地址（填写所有必填字段），保存后设为默认地址
**Then** 该地址在列表显示，且被标记为默认退货地址

#### SC-CONFIG-03：操作员角色 — 地址配置权限
**Give** 管理员编辑某操作员角色
**When** 勾选"地址配置"及其子权限"新增地址""编辑""删除"，保存角色
**Then** 该角色用户登录后可访问地址配置菜单并执行对应操作
