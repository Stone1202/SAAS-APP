## 1. 背景与问题陈述

本卷涵盖「百货商城」**小程序端** 的全部功能，来源为原型版本 v1.6.1。包含退款审核、退款/售后订单、收货管理、我的订单/店铺订单、待收货入口显隐控制、更多模块显隐控制、福利券、未登录/未绑定展示商品、退货返厂等模块。

**忠实还原声明**：本文档严格遵循 FR-01~FR-05 铁律，原型有什么就还原什么，不做删减、纠偏或推测补充。

#### FN-MP-01：同意退款时退货地址回显

| 属性 | 值 |
|------|-----|
| 编号 | FN-MP-01 |
| 用例编号 | UC-MP-01 |
| 名称 | 店长同意退款时退货地址回显 |
| 页面 | 退款审核 |
| 参与者 | 店长 |
| 优先级 | P1 |
| 关联BG | — |
| 自动化类型 | 手动 |

**前置条件**：用户申请退货退款，店长在退款审核页面操作点击"同意"

**基本流程**：

**自提订单退货地址**：
1. [系统自动] 根据后台配置项"自提订单退货地址是否默认为门店地址"判断

3. [系统自动] 配置为"是"时：直接默认回显门店的地址信息

**快递到家订单退货地址**：
1. [系统自动] 若订单商品关联了供应商，退货地址回显供应商的地址信息
2. [系统自动] 若未关联供应商，退货地址回显平台的地址信息

**数据范围**：R

**后置条件**：弹窗显示退货地址信息

## 3. 业务规则（BR）

### BR-MP-01：游客下单跳转
**触发条件**：未登录用户点击"去下单"
**行为**：跳转至登录页

### BR-MP-02：未绑定门店购买限制
**触发条件**：已登录但未绑定门店的用户下单
**行为**：只能购买快递到家商品

### BR-MP-03：待收货入口显隐规则
**触发条件**：配置"是否显示待收货订单状态"为"否"
**行为**：我的页面待收货入口隐藏；我的订单和店铺订单待收货tab隐藏

### BR-MP-04：填写物流单号显隐规则
**触发条件**：用户查看售后详情页
**行为**：
- 自提订单：根据配置"自提订单退货是否需要填写物流信息"决定
  - 否：不显示"填写物流单号"按钮
  - 是：显示按钮
- 快递到家订单：一定显示按钮

### BR-MP-05：包裹默认展示规则
**触发条件**：多个包裹
**行为**：默认展示2个，超过则折叠，支持展开/收起

### BR-MP-06：物流弹窗包裹选择
**触发条件**：同一快递公司多个快递单号
**行为**：弹窗显示包裹选择列表+全部选项；选择后展示对应轨迹并关闭弹窗

### BR-MP-07：福利券来源标注
**触发条件**：后台操作员发放福利券
**行为**：领取说明记录为"系统后台发放"

## 5. 验收标准

### 场景级 E2E

#### SC-MP-01：游客浏览商品并跳转登录
**Give** 用户未登录访问小程序首页
**When** 看到提审商品列表，点击"去下单"
**Then** 跳转至登录页面

#### SC-MP-02：退货退款物流填写
**Give** 用户申请退货退款（自提订单），后台配置"自提订单退货是否需要填写物流信息"为"否"
**When** 用户查看售后详情页
**Then** 不显示"填写物流单号"按钮

#### SC-MP-03：多包裹物流查看
**Give** 订单关联同一快递公司多个快递单号
**When** 用户点击"查看物流"
**Then** 弹窗显示包裹1、包裹2...和"全部"选项；选择后展示对应物流轨迹

#### SC-MP-04：待收货入口配置联动
**Give** 后台配置"是否显示待收货订单状态"改为"否"
**When** 用户进入小程序"我的"页面
**Then** 待收货入口不显示；我的订单/店铺订单中待收货tab不显示

#### SC-MP-05：退货返厂完整流程
**Give** 店长进入退货返厂页面
**When** 搜索商品，点击"确定返厂"提交申请
**Then** 状态变为"审核中"，待平台审核
